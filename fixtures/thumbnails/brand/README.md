# Miniatures YouTube — logo 4K (fixe)

Ce logo est **toujours** le même sur toutes les miniatures, placé en **haut à gauche**.

## Où le mettre

### Dev (repo)

```
fixtures/thumbnails/brand/4k-logo.png
```

ou

```
fixtures/thumbnails/brand/4k-logo.svg
```

### Release (app installée)

```
Documents\CS2-POV-Generator\assets\thumbnails\brand\4k-logo.png
```

## Règles

- Format conseillé : **PNG avec transparence** (ou SVG)
- Noms acceptés (premier trouvé) : `4k-logo.png`, `4k-logo.webp`, `4k-logo.jpg`, `4k-logo.svg`
- Un SVG de secours `4k-logo.svg` est fourni dans le repo — **remplace-le** par ton vrai badge 4K si besoin
- Pas de sélecteur dans l’UI : le fichier est chargé automatiquement s’il existe
